# Branch Naming Convention — Developers

## Format

```text
<descriptive-branch-name>-<developer-name>
```

## Rule

Every branch created by a developer must contain a short, descriptive name indicating the work being performed, followed by a hyphen (`-`) and the developer's name.

Branch names must be written without spaces and using hyphens to separate words.

## Explanation

This convention makes it possible to quickly identify **what is being developed** and **who is responsible for the branch**.

**Example:** `implement-user-login-jose`
