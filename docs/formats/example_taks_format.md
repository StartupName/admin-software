# Example

## Objective
Create the reusable `MetricCard` component used to display key indicators on the Dashboard.

## Reference

[View Dashboard documentation](../docs/prototypes/dashboard/README.md#6-information-cards-component)

## Location

```text
src/components/dashboard/MetricCard/
```

## Requirements

* Receive title, value, and icon via `props`.
* Be reusable for different metrics.
* Maintain the design established in the prototype.
* Adapt to values ​​of varying sizes.

## Recommended Knowledge

* JSX.
* Props.
* React components.
* CSS Flexbox/Grid.

## Acceptance Criteria

* The component can render different metrics.
* Data is not hardcoded.
* The design matches the visual reference.
* No console errors.
* The code is located in the specified directory.
